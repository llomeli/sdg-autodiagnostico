# Prompt: explicar el producto a una audiencia

> Usa el documento `docs/01_PRODUCTO_Y_MODELO.md` y el código del paquete para preparar una explicación de 3 minutos del “Modelo de madurez de gobierno del dato” dirigida a [dirección / gobierno de datos / Marketing / TI / prospectos]. Explica: para quién es, qué problema de negocio ayuda a poner en conversación, el flujo de 3 pasos, los 11 dominios, las 46 preguntas, la escala 0–5/N/A y qué recibe la persona. Deja claro que es autodiagnóstico orientativo y gratuito, no auditoría/certificación/opinión legal. Distingue qué datos se capturan para el puntaje y cuáles se capturan para calificar y seguir un lead. Indica qué no hace el MVP (sin email automático, sin CRM) y qué debe estar listo antes de captar datos reales (Aviso de Privacidad aprobado y flujo de seguimiento). No inventes benchmarks, umbrales, correlaciones ni recomendaciones que no existan en el producto.

## Prompt para respuesta a dudas de propiedad intelectual

> Contesta las inquietudes del equipo de Gobierno de Datos sobre la exposición metodológica del lead magnet. Usa tono transparente y prudente. Explica que se tomaron 46 preguntas adaptadas de un cuestionario SDG/DMBOK de 121 preguntas para una experiencia breve; la estructura por dominio y la escala visible no constituyen el método completo. Especifica que el activo público no debe incluir las hojas internas del workbook, trazabilidad privada, ponderaciones, criterios de severidad, playbook, benchmarks, plantillas o aceleradores. Si no puedes confirmar un detalle leyendo el contenido incluido, decláralo como pendiente y pide revisión, no supongas.
